# GP screening cost estimator (costbot)

Streamlit proof of concept that produces Class 5 screening cost estimates for
capital projects. Ten deterministic models (parametric calculators, analogue
matching, equipment similarity, chip composition, subsea and OSBL overlays)
fire progressively as the user adds scope detail; an ensemble combines them
into a P50, a P20 to P80 range and a confidence tier. No LLM, no database:
everything runs from flat files.

The specification is the manager's task brief and its update email, kept
verbatim in [`docs/spec/`](docs/spec/). Where the code deliberately deviates
from it, [`docs/BACKLOG.md`](docs/BACKLOG.md) says so.

## Quick start

```bash
make install          # venv with Python 3.13 (Anaconda) + requirements
make run              # http://localhost:8501
make test             # unit tests, golden baseline, engine smoke, headless UI
```

Without `make`:

```bash
/opt/anaconda3/bin/python3.13 -m venv .venv
.venv/bin/pip install -r requirements.txt -r requirements-dev.txt
.venv/bin/streamlit run app.py
```

## Data

`data/` is a **synthetic** package generated by `scripts/generate_mock_data.py`.
It has the file names, row counts and columns of the confidential package the
engine was written for, with random values. Nothing computed on it says
anything about accuracy. To use the real package, point the engine at it:

```bash
export COSTBOT_DATA_DIR=/path/to/real/data
.venv/bin/streamlit run app.py
.venv/bin/python scripts/evaluate_truth.py --csv results.csv   # hit rate at +/-30% per archetype
```

Step-by-step for the real-data validation: [`docs/VALIDATION_RUNBOOK.md`](docs/VALIDATION_RUNBOOK.md).

## Layout

| Path | What |
|---|---|
| `app.py`, `app_pages/`, `ui/`, `.streamlit/` | Streamlit app: entry point, three pages, shared UI, theme |
| `costbot/` | The engine: constants, data store, escalation, one module per model, ensemble, screening, report |
| `engine.py` | Compatibility facade over `costbot` |
| `tests/`, `scripts/` | pytest suites; mock data, smoke, headless UI, screenshots, truth evaluation |
| `docs/` | Spec (`spec/`), app documentation, demo script, review, backlog |
| `data/` | Mock data package |

Conventions for contributors (and for Claude Code) are in [`CLAUDE.md`](CLAUDE.md).
Deployment target is a Databricks App (`app.yaml`); Streamlit 1.52 or newer is required.
