# Spec vs. implementation review (2026-09-26)

Scope: compare the AI-built POC (`app.py`, `engine.py`, docs) against the
manager's brief (`README.md` of Sep 15, email of Sep 16, `wireframe.md`).
Reviewed by reading every file; runtime checks done on mock data only.

## 1. Blocking: the data package and reference code are not available

The engine expects 10 CSVs plus a golden JSON under `data/`, and the README
names `cost_bot_api.py` as the single source of truth that the app must
match "output for output". Neither is in the workspace and the zip is
confidential. Until we have them:

- pool-based models (Benchmark, EquipmentVector, Unconventional, Composite)
  can only be exercised on synthetic data;
- "identical outputs for identical inputs" against `cost_bot_api.py` cannot
  be checked at all;
- every accuracy figure in `APP_DOCUMENTATION.md` and `DEMO_SCRIPT.md`
  (84%, 42/50, per-archetype tables) is an unverified claim. There is no
  script in the repo that produces those numbers.

Ask: a sanitized copy of the data (or read access on a shared drive) and
the reference modules, even without the evaluation harness.

## 4. UI vs. wireframe / demo script

- Location dropdown is a mixed list (regions and countries), labelled
  "CP30 Region". Should be driven by `ref_country_to_cp30_location.csv`.
- Facility Type is free text. The wireframe wants dropdowns; the engine only
  knows ~50 facility keys, so a typo silently disables Calculator_Onshore.
  Replace with a selectbox built from `ISBL_CORRELATIONS` + `_FACILITY_ALIASES`.
- "Data Package" tab lists "CET Rate CSVs (36 files)" and "Code Inventory"
  lists 16 modules with line counts; none of these files exist in the
  package. Remove or mark as "reference only, not shipped".
- `APP_DOCUMENTATION.md` file inventory mentions `PENDING.md`, which does
  not exist.
- Process Domain and Scope Type are collected but Process Domain only feeds
  the top-level analogue table, not Benchmark's encoding (Benchmark derives
  it from archetype). Either wire it in or drop the field.
- `use_container_width=True` is deprecated in current Streamlit; harmless
  warnings for now.

## 5. Engine quality observations (not bugs, worth a look)

- `run_benchmark` re-encodes and re-fits a `StandardScaler` on the full
  pool on every call. Cache the encoded matrix per `DataStore`.
- `run_equipment_vector` parses 593 JSON vectors per call with `iterrows`.
  Pre-parse once into a numpy matrix.
- `run_composite` runs `DataFrame.apply` with a Python scorer over 857 chips
  per scope item. Acceptable for a POC, slow for what-if loops.
- `_convert_capacity` mixes cross-family conversions (KTA to BPD via a fixed
  density). Document the assumption or refuse the conversion.
- `Calculator_Offshore` ignores the user's `water_depth_m` unless it is
  inside `secondary_params`; the app duplicates it there, but the
  what-if path only patches `secondary_params` for two keys.
- `ARCHETYPE_MODELS` has no entry for `lng_offshore` in the UI options and
  `pipeline_gathering` is in the engine but not in the UI dropdown.
- No unit tests for the ensemble logic (`_assess_confidence`): spread gate,
  geometric blend, unconventional override, 5x cap. These are the rules
  David wrote down; they deserve direct tests independent of data.
